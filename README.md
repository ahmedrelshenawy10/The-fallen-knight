This is my first 2D game as a beginner game developer, it is about a knight that roams the world to collect coins, the game is still in development and I am learning actively to build it.

HOW TO PLAY: 
UP DOWN LEFT RIGHT arrows for movement. SPACE for jump.

Game engine and programming language:
The game is built with godot 4 and GDScript.

Installation and Running:
Download The-fallen-dark-knight ZIP file and extract the file, then run the .exe app to open the game. 

structer:
It consists of .godot, addons, assets, scenes, and scripts folders that are the main structure of the game aside of the addons because it only contains the wakatime to track the time of building the game.

Improvements: 
I plan to improve the mechanics of the game and the movement of the player, add enemies, add health bar, and make the map bigger for the player to explore it.
